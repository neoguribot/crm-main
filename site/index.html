기능Features
고객 관리
등록·조회·수정·삭제. 유입경로, 구매목적(복수 선택), 첫 방문일과 메모까지 한 장에.
거래 기록
고객별 판매·매입 이력. 품목·중량·순도·금액을 정밀 수치로 남깁니다.
세그먼트 검색
이름·전화 검색에 구매목적·유입경로·미방문 기간(30·90·180·365일) 필터를 겹쳐 봅니다.
대시보드
전체 고객 수, 이달 판매·매입 금액, 90일 미방문, 구매목적 분포, 최근 거래.
리마인드

만든 방식How it's built
  • 정밀 수치금액·중량·순도는 PostgreSQL numeric에 저장하고 앱에서는 문자열로 다뤄, 부동소수점 오차를 배제합니다. (24K · 99.99% · 3.750g)
  • 시간대 고정모든 날짜·시각 기준은 Asia/Seoul. 순수 날짜는 date, 타임스탬프는 UTC로 저장합니다.
  • 행 수준 보안모든 테이블에 Row Level Security. 로그인한 직원은 자기 고객·거래만 조회합니다.
  • 서버 우선기본은 Server Component. 데이터 변경은 Server Action, 인증 콜백은 Route Handler로.
  • 계산은 조회 시최근 방문일·리마인드 상태는 저장하지 않고 조회 시점에 계산합니다.
